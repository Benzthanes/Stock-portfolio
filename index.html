เกี่ยวกับหน้า

ไฟล์นี้เป็นหน้าเริ่มต้น (index.html) ของโปรเจกต์ Stock-portfolio — คุณสามารถแก้เนื้อหา HTML, ใส่รูป, หรือลิงก์เพิ่มเติมได้ตามต้องการ

คำแนะนำเพื่อเผยแพร่ให้คนอ่านได้

  1. เปิด GitHub Pages ใน Settings ของ repository นี้ (Settings → Pages) แล้วเลือกสาขา (เช่น main) และโฟลเดอร์ (root หรือ /docs)
  2. ถ้า repository เป็นแบบ private และคุณต้องการให้คนทั่วไปเข้าชม คุณต้องเปลี่ยนเป็น public หรือใช้บริการโฮสต์ เช่น Netlify / Vercel
  3. หลังเปิด GitHub Pages จะได้ URL ที่คนอื่นสามารถเข้าชมได้ เช่น https://<username>.github.io/Stock-portfolio/

ถ้าต้องการ ผมช่วยตั้งค่า Pages ให้ (ผมต้องการอนุญาตหรือให้คุณบอกว่าจะเปลี่ยน repo เป็น public หรือไม่)
