# Project Essentials Rule (Always-On)

ก่อนเริ่มงานทุกครั้ง ให้อ่าน `AGENTS.md` ที่ root ของโปรเจกต์ให้จบ. ไฟล์นั้นคือกฎหลักของโปรเจกต์.

กฎ 3 ข้อที่ห้ามพลาดแม้ยังไม่ได้อ่าน:
* ไฟล์ `data/portfolio.json`, `data/trades.json` และ `data/ledger.json` คือบัญชีเงินจริง. ห้ามเขียนทับโดยไม่ได้ dry-run และไม่ได้รับอนุมัติจากผู้ใช้.
* คะแนนหุ้นทุกหน้ามาจาก `src/scoring.py` แหล่งเดียว. อินดิเคเตอร์จะได้คะแนนเมื่อผ่าน backtest แล้วเท่านั้น.
* งานถือว่าเสร็จเมื่อเทสต์ผ่าน `portfolio.py --all` จบด้วย exit 0 และเปิดหน้า HTML ตรวจแล้ว ตามหัวข้อ 5 ของ `AGENTS.md`.
