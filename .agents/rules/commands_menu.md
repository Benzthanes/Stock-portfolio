# Interactive Command Function Prompting Rule

เมื่อผู้ใช้พิมพ์คำสั่งสั้นๆ เช่น `/port`, `/fix`, หรือ `/dip` โดยไม่ได้ระบุพารามิเตอร์ต่อท้าย:

1. **รันตัวเลือก (Recommended) ทันทีโดยไม่ต้องถามก่อน**:
   - ห้ามถามเมนูก่อนรัน. ให้รันตัวเลือกที่มีป้าย (Recommended) ทันที.
   - เมื่อแสดงผลเสร็จ ให้ปิดท้ายด้วยรายการตัวเลือกอื่นแบบสั้น 1 บรรทัดต่อตัวเลือก เพื่อให้ผู้ใช้พิมพ์ต่อได้เลย.

2. **เมนูตัวเลือกสำหรับแต่ละคำสั่ง**:
   - **เมื่อผู้ใช้พิมพ์ `/port`**:
     - รันรายงานสุขภาพพอร์ตแบบ All-in-One ทันทีโดยไม่ต้องแยกคำสั่งย่อย. ครอบคลุมทั้งการวิเคราะห์สุขภาพพอร์ต, ระดับความเสี่ยงการกระจุกตัว (HHI), จังหวะสะสมหุ้น Value Zone, และอันดับหุ้นน่าซื้อเพิ่มเมื่อมีเงินสดใหม่ (Fresh Capital Top Picks).
   - **เมื่อผู้ใช้พิมพ์ `/fix`**:
     - `(Recommended) /fix`: รันแผนกู้พอร์ต 360 องศา สรุปภาพรวมหุ้นติดลบทุกตัวในพอร์ตทันที.
     - `/fix [TICKER]`: เจาะลึกแผนแก้ดอยหุ้นรายตัว (เช่น `/fix APP`, `/fix NOK`, `/fix TSLA --shares 10 --cost 250`).
   - **เมื่อผู้ใช้พิมพ์ `/dip`**:
     - `(Recommended) /dip`: สแกนหาหุ้นย่อตัวชั้นนำที่ดีที่สุดประจำวัน.
     - `/dip best`: กรองเฉพาะหุ้นที่มี Reward-to-Risk คุ้มค่าตั้งแต่ 2.0 เท่าขึ้นไป.
     - `/dip growth`: กรองเฉพาะหุ้นที่รายได้เติบโตเป็นบวก (Quality Growth).
     - `/dip tech`: สแกนหาหุ้นย่อตัวเฉพาะกลุ่มเทคโนโลยี.
     - `/dip finance`: สแกนหาหุ้นย่อตัวเฉพาะกลุ่มสถาบันการเงินและธนาคาร.
     - `/dip [TICKER]`: ระบุชื่อหุ้นที่สนใจตรวจสอบรายตัว.

3. **ภาษาและสไตล์**:
   - ปฏิบัติตามกฎ Poteto Mode เสมอ (ประโยคบอกเล่าสั้นๆ ลงท้ายด้วยจุด ไม่มีขีดยาว ไม่มีโคลอนกลางประโยค).
