# 📈 Filter Stock: ระบบวิเคราะห์พอร์ตหุ้นสหรัฐฯ และแผนแก้ดอยฉบับภาษาคน

> สำหรับ AI agent (Gemini, Claude, Codex) ให้อ่าน [AGENTS.md](AGENTS.md) ก่อนเริ่มงานทุกครั้ง.

ระบบวิเคราะห์การลงทุนหุ้นสหรัฐฯ สำหรับมือใหม่.
ไม่ต้องดูกราฟเป็น และไม่ต้องคำนวณงบการเงินเอง.
ระบบเชื่อมต่อข้อมูลราคาและบทวิเคราะห์จาก Wall Street และ TradingView แบบสดใหม่ทุกวัน.
สรุปผลลัพธ์เป็นภาษาคนที่เข้าใจง่าย พร้อมบอกขั้นตอนที่ต้องทำทันที 1-2-3.

## ⚡ คำสั่งหลักที่คุณต้องใช้ (ใช้งานง่ายผ่านห้องแชท)

คุณไม่จำเป็นต้องจำคำสั่งโปรแกรมมิ่งยาวๆ.
เพียงพิมพ์คำสั่งสั้นๆ เหล่านี้ในช่องแชท:

### 🌟 `/all` อัปเดตทุกรายงานพร้อมกันในคลิกเดียว (All-in-One Refresh)
- รันอัปเดตข้อมูลสดของทั้ง 7 รายงานให้พร้อมกันในรอบเดียว:
  1. แดชบอร์ดภาพรวมพอร์ต ([portfolio_master.html](reports/portfolio_master.html))
  2. รายงานตรวจสุขภาพพอร์ต ([portfolio_review.html](reports/portfolio_review.html))
  3. กลยุทธ์ฟื้นฟูแก้ดอย ([portfolio_recovery.html](reports/portfolio_recovery.html))
  4. พอร์ตจำลองช้อนซื้อ Dip ([portfolio_dip_sim.html](reports/portfolio_dip_sim.html))
  5. บัญชีประวัติปิดการขาย ([trades_ledger.html](reports/trades_ledger.html))
  6. หน้ากราฟและ AI เต็มจอ ([stock_chart.html](reports/stock_chart.html))
  7. หุ้นที่สนใจตามแนวรับ Fibo ([watchlist.html](reports/watchlist.html))
- ทุกรายงานมีแถบเมนูด้านบนสำหรับสลับหน้า และแสดงเวลาอัปเดตล่าสุด.
- หรือรันผ่าน Terminal ด้วยคำสั่ง: `python3 portfolio.py --all`

### 1. `/master` แดชบอร์ดความมั่งคั่งรวม (Master Wealth Dashboard)
- รวบรวมสินทรัพย์ทั้งหมด: เงินฝาก KKP, หุ้นสด Dime!, กำไรที่ปิดแล้ว และเงินปันผลสะสม.
- คำนวณมูลค่าสุทธิรวม (Total NAV) และกำไรสุทธิสะสมทั้งหมด.

### 2. `/port` ตรวจสุขภาพพอร์ตโฟลิโอฉบับ All-in-One ครบจบในคำสั่งเดียว
- ประเมินสุขภาพพอร์ตโดยรวมออกมาเป็นเกรด A+ ถึง D (เช่น เกรด A+, A, B+, B, C, D) พร้อมคะแนน 0 ถึง 100.
- สรุปตัวเลขทางการเงิน กำไร ขาดทุนสุทธิทั้งสกุลเงินดอลลาร์ ($) และเงินบาท (฿).
- ชี้เป้าหุ้นฮีโร่ที่ทำเงินสูงสุด และหุ้นตัวฉุดที่ติดลบหนักที่สุด.
- ตรวจสอบความเสี่ยงการกระจุกตัว (Risk & Concentration) ด้วยค่า HHI และสัดส่วนกลุ่มธุรกิจ (Sector Allocation).
- สแกนหาจังหวะสะสม DCA และ Technical Dip ที่ย่อตัวลงมาในจุดรับสถาบัน (Value Zone).
- แนะนำ 3 อันดับหุ้นในพอร์ตที่น่าซื้อเพิ่มที่สุดหากมีเงินสดใหม่ พร้อมเตือนตัวที่ห้ามซื้อเด็ดขาด และสูตรแบ่งเงิน 3 ไม้.
- ตารางราคาเป้าหมายจากสถาบันการเงินวอลล์สตรีท (ราคาเฉลี่ย กรอบต่ำสุดถึงสูงสุด และมติ ซื้อ ถือ ขาย).
- เช็กลิสต์ 3 ข้อที่มือใหม่ต้องทำทันทีในวันนี้.

### 3. `/fix` แผนแก้หลุดดอย 360 องศา
- คัดแยกหุ้นที่ติดลบออกเป็นระดับความเร่งด่วนตามสี 🟢 ดอยปลอดภัยถือรอได้, 🟡 ดอยปานกลางรอจังหวะ, 🔴 ดอยอันตราย.
- ตารางเปรียบเทียบ 3 ทางเลือกแบบฟันธง:
  1. ทางเลือกที่ 1 ถือรอเฉยๆ (Hold)
  2. ทางเลือกที่ 2 ถัวแบบฉลาดตามแนวรับ (Smart DCA) พร้อมคำนวณเงินและจำนวนหุ้นที่ต้องซื้อเพิ่ม
  3. ทางเลือกที่ 3 สลับตัวกู้พอร์ต (Capital Rotation) ย้ายเงินไปเข้าหุ้นผู้นำตัวอื่นเพื่อดึงทุนคืน
- เปรียบเทียบต้นทุนของคุณกับราคาเป้าหมายของสถาบัน เพื่อดูว่ามีโอกาสหลุดดอยจริงหรือไม่.
- คู่มือการเปิดแอปโบรกเกอร์ (เช่น Dime, InnovestX หรือ IBKR) เพื่อตั้งคำสั่ง Limit Order และ Stop Loss.

### 4. `/dip` สแกนหาหุ้นดีราคาถูกน่าช้อนซื้อ
- สแกนหุ้นยักษ์ใหญ่สหรัฐฯ ใน S&P 100 และ Nasdaq 100 ที่ย่อตัวลงมาในโซนราคาปลอดภัย (Value Zone).
- แปะป้ายความเหมาะสมสำหรับมือใหม่ (🟢 เหมาะกับมือใหม่ / 🟡 ปานกลาง / 🔴 เสี่ยงสูง).
- เช็กลิสต์ 3 ข้อป้องกันการรับมีดหล่น (งบไม่พัง สถาบันไม่เทขาย ไม่มีคดีความ).
- สูตรแบ่งเงิน 3 ไม้ช้อนซื้อ เพื่อป้องกันการติดดอยซ้ำซ้อน.
- กำหนดจุดยอมแพ้ตัดขาดทุน (Stop Loss) และเป้าหมายทำกำไร (Take Profit) ชัดเจนทุกตัว.

## ✍️ บันทึกรายการใหม่ (ไม่ต้องแก้โค้ด)

เมื่อซื้อหุ้น ขายหุ้น ฝากเงิน ถอนเงิน หรือได้ปันผล ให้บอกในแชท หรือรันคำสั่งเหล่านี้.
จากนั้นรัน `/all` เพื่ออัปเดตรายงาน.

```bash
python3 trades.py buy -t BAC -s 2 -p 48.10          # ซื้อหุ้น คำนวณต้นทุนเฉลี่ยใหม่และตัดเงินสดให้อัตโนมัติ
python3 trades.py sell -t VST -p 160.50             # ขายหุ้นทั้งหมด (ใส่ -s เพื่อขายบางส่วน)
python3 trades.py deposit --amount 20000            # ฝากเงินเข้า Dime! Save
python3 trades.py withdraw --amount 5000            # ถอนเงินออก
python3 trades.py dividend -t LLY --usd 3.50        # รับเงินปันผล
```

- ทุกคำสั่งใส่ `--dry-run` เพื่อดูผลก่อนบันทึกจริงได้.
- ใส่ `--date YYYY-MM-DD` เมื่อบันทึกย้อนหลัง.

## 💡 ระบบถามตัวเลือกฟังก์ชันอัตโนมัติ (Interactive Menu)

เมื่อคุณพิมพ์คำสั่งสั้นๆ เช่น `/fix` หรือ `/dip` ระบบจะรันตัวเลือกแนะนำทันที.
เมื่อแสดงผลเสร็จ ระบบจะบอกตัวเลือกอื่นที่พิมพ์ต่อได้:
- คำสั่ง `/port`: ทำงานแบบ All-in-One ทันที ไม่ต้องเลือกฟังก์ชันย่อยซ้ำซ้อน เพราะรายงานรวบรวมทั้งตรวจสุขภาพ, ตรวจความเสี่ยง, สแกน DCA และจัดอันดับซื้อเพิ่มไว้ให้ครบแล้วในคำสั่งเดียว.
- ตัวอย่างคำสั่ง `/fix`: มีตัวเลือกให้เลือกระหว่าง แผนกู้พอร์ตภาพรวม, หรือเจาะลึกหุ้นรายตัวเช่น `/fix APP`, `/fix NOK`, `/fix BAC`.
- ตัวอย่างคำสั่ง `/dip`: มีตัวเลือกให้เลือกระหว่าง หุ้นย่อตัวที่ดีที่สุด, หุ้นที่มีความคุ้มค่าสูง, หรือหุ้นเฉพาะกลุ่มเทคโนโลยี.

## 📖 พจนานุกรมแปลศัพท์ฉบับ 1 บรรทัด สำหรับคนไม่เคยเล่นหุ้น

- **Rev YoY:** การเติบโตของยอดขายเทียบกับปีก่อนหน้า ตัวเลขเป็นบวกแปลว่าบริษัทยังขายดี.
- **Net Inc YoY:** การเติบโตของกำไรสุทธิ บ่งบอกว่าบริษัทหาเงินเข้ากระเป๋าได้เก่งขึ้นจริงหรือไม่.
- **PEG:** ความคุ้มค่าของราคาเทียบการเติบโต ต่ำกว่า 1.0 แปลว่าราคาไม่แพง.
- **P/E:** อัตราส่วนราคาต่อกำไร บอกจำนวนปีคืนทุน ค่ายิ่งต่ำยิ่งปลอดภัย.
- **Daily RSI:** ดัชนีวัดแรงซื้อขาย ถ้าต่ำกว่า 30 แปลว่าคนเทขายหนักจนราคาถูก มีโอกาสเด้งกลับ.
- **Value Zone 💎:** โซนราคาใกล้เส้น 200 วัน เป็นจุดที่สถาบันการเงินใหญ่ใช้สะสมหุ้น.
- **Breakeven Gap:** เปอร์เซ็นต์ที่ราคาหุ้นต้องวิ่งขึ้นเพื่อให้คุณกลับมาเท่าทุนเดิม (0%).
- **Stop Loss (SL):** ราคาตัดขาดทุนเด็ดขาดหากตลาดผิดทาง เพื่อปกป้องเงินก้อนใหญ่ไว้.
- **Take Profit (TP):** ราคาเป้าหมายขายทำกำไรเพื่อล็อกเงินเข้ากระเป๋า.

## 🛡️ กฎเหล็ก 5 ข้อห้ามเด็ดขาดของมือใหม่

1. **ห้ามถัวหุ้นที่กำไรหดตัวหรือกำลังมีคดีความ:** ยิ่งถัวเงินจะยิ่งจม อย่าเอาเงินดีไปถมในธุรกิจที่มีปัญหา.
2. **ห้ามทุ่มเงินซื้อไม้เดียวหมดหน้าตัก:** ให้แบ่งเงินเป็น 2 ถึง 3 ไม้เสมอ เพราะตลาดมีโอกาสย่อตัวอีก.
3. **ห้ามซื้อหุ้นก่อนวันประกาศงบการเงิน 14 วัน:** วันประกาศงบราคามักผันผวนรุนแรงเหมือนแทงหวย ควรรอให้งบออกเสร็จสิ้นก่อน.
4. **ห้ามขายหุ้นกำไรเพื่อเอาเงินไปถัวหุ้นขาดทุนหนัก:** ยึดหลักการอย่าตัดดอกไม้ทิ้งเพื่อไปรดน้ำวัชพืช.
5. **ห้ามถือหุ้นโดยไม่มีจุดตัดขาดทุน (Stop Loss):** การยอมขาดทุนเล็กน้อย 5% แก้ไขได้ง่ายกว่าการปล่อยให้ติดลบ 50%.

## 🛠️ Setup & Development

- ใช้ Python 3.11 และไม่มี dependency ภายนอก (ใช้แค่ standard library).
- อัปเดตทุกรายงาน: `python3 portfolio.py --all` (หรือ `python3 -m portfolio --all`).
  ถ้ามีขั้นตอนไหนพัง รายงานอื่นยังสร้างต่อ แต่คำสั่งจะจบด้วย exit code 1.
- รัน test: `python3 -m unittest discover -s tests -t .`.
  test ถูกบล็อกไม่ให้ต่อเน็ตจริง ตั้ง `ALLOW_NETWORK=1` ถ้าต้องการปิดการบล็อก.
- Lint (ไม่บังคับ): `uvx ruff check .` ใช้ค่าจาก `pyproject.toml`.
- CI: `.github/workflows/update_portfolio.yml` รันจันทร์ถึงศุกร์ 13:39 และ 21:12 UTC.
  GitHub มักรันช้ากว่าเวลาที่ตั้งไว้ 2 ถึง 4 ชั่วโมง.
  ถ้ารันพัง จะเปิดหรือคอมเมนต์ใน issue ที่มี label `portfolio-update-failure`.
- Claude skills อยู่ที่ `.agents/skills/` และเข้าถึงผ่าน symlink `.claude/skills`.
